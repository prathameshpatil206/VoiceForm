Non-Standard / Difficult Form

Intentionally unusual patterns — documents limitations honestly

⚠️ This page tests edge cases. Some may result in PARTIAL or FAIL status — this is expected and documented.

Section 1 — Fields Outside <form>

✅ VoiceForm supports orphan fields via the orphan-field scanner path (M1). Expected: PASS.

Section 2 — Label After Input

⚠️ Labels placed after inputs may not be resolved by proximity-based label detection. VoiceForm uses label[for] → fallback → placeholder — label-after may degrade to placeholder. Expected: PARTIAL.

Section 3 — Custom Div-Based Dropdown

⚠️ Custom div-based dropdowns are not native <select> elements. VoiceForm's M2 DOM filler operates on native controls only. A hidden real <select> is included for scanner detection, but the visual dropdown will not be filled by VoiceForm. Expected: PARTIAL (scanner detects hidden select; visual dropdown not filled).
